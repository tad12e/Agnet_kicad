# Code Reviewer Skill

When reviewing Python code in this workspace:
1. **Style & Formatting:** Verify adherence to PEP8 guidelines and proper docstrings.
2. **Type Annotations:** Check that type hints (typing module) are complete and accurate.
3. **Safety & Logic:** Ensure edge cases, missing exception handlers, and boundary conditions are handled properly.
4. **KiCad Agent Integrity:** Validate compatibility with KiCad schematic and symbol data structures.
